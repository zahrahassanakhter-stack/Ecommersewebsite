# E-Commerce Website

A responsive front-end e-commerce website built using HTML, CSS, and JavaScript as part of the Developer Hub Cooperation Internship.

## About

This project recreates the interface of a modern online shopping website. It includes multiple pages with a clean design and responsive layout for different screen sizes.

## Features

- Responsive design
- Home page
- Product listing page
- Product details page
- Shopping cart
- Search functionality

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
